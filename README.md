# ZENIX Professional

Landing Page desenvolvida para a **ZENIX Professional**, marca de cosméticos capilares profissionais, com foco em apresentação institucional, divulgação de produtos, captação de parceiros e atendimento via WhatsApp.

## ✨ Sobre o projeto

A proposta da landing page é apresentar a **ZENIX Professional** de forma moderna, elegante e sofisticada, reforçando seu posicionamento no mercado de beleza profissional.

A marca trabalha exclusivamente com **profissionais da beleza, salões e revendedoras credenciadas**, sem vendas diretas ao consumidor final.

O projeto possui design responsivo, identidade visual personalizada, catálogo de produtos e áreas estratégicas voltadas para apresentação da marca e captação de novos parceiros.

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- Heroicons

## 📱 Funcionalidades

- Hero Section responsiva
- Apresentação institucional da marca
- Categorias e linhas de produtos
- Catálogo de produtos
- Modal com detalhes dos produtos
- Integração com WhatsApp
- Diferenciais da empresa
- Depoimentos
- Cadastro para profissionais e revendedores
- Chamada para novos parceiros (CTA)
- Footer com informações e links
- Design totalmente responsivo
- Animações e interações suaves
- Favicon personalizado
- SEO básico
- Open Graph para compartilhamento do site

## ▶️ Executando o projeto

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local para acessar o projeto.

## 📦 Build

Para gerar a versão de produção:

```bash
npm run build
```

A versão otimizada para produção será gerada na pasta:

```text
/dist
```

## 🖼️ Assets

As imagens, logos, favicon e demais arquivos públicos utilizados no projeto estão localizados em:

```text
/public
```

Os demais assets utilizados pela aplicação estão em:

```text
/src/assets
```

## 🎨 Design

A identidade visual e a interface foram desenvolvidas com foco em:

- Elegância
- Feminilidade
- Sofisticação
- Beleza profissional
- Experiência do usuário
- Responsividade
- Conversão

A interface utiliza uma paleta em tons de **rosa, creme e branco**, seguindo o posicionamento visual da ZENIX Professional.
